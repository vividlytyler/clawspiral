OpenClaw has shipped **v2026.7.2**, one of its largest releases yet, introducing a sweeping set of features spanning reliability, developer experience, and new platforms.

## Key Highlights

### Session Rewind and Branching
Perhaps the most user-facing change: conversations can now be **rewound or forked** from any message. Users can switch transcript branches across web and native apps, fork upstream Codex sessions, and restore prompt images after a fork. Session boards and dashboards gain archived, visibility, draft, and incognito states.

### Interactive MCP Apps and Dashboards
OpenClaw now hosts **ticketed MCP Apps** with bound tools, resources, and bounded context updates. Apps open from channel replies, can be pinned to durable dashboards, and native plugins can declare them directly.

### Durable Channel Delivery
A critical reliability improvement: messages across **Telegram, Signal, Slack, QQBot, Twitch, Synology Chat, Tlon, IRC, and Zalo** are now recoverable across gateway restarts and local crashes through a shared ingress drain and dead-letter recovery system.

### Meetings and Realtime Talk
OpenClaw now joins **Teams, Zoom, and Google Meet** calls as a meeting guest with default-enabled plugins and durable transcript collection. Realtime Talk adds OpenAI and Gemini video support.

### State Safety and Recovery
The release introduces a **quarantine store** that survives primary-database damage, crash-recoverable SQLite snapshots, crash-durable filesystem publication, schema-upgrade data-loss rejection, and rollback-writer snapshot recovery.

### Wear OS Companion
A new phone-proxied Wear companion app delivers home-screen agent/session/model selection, realtime Talk controls, audio-reactive playback, and an instant-talk tile.

### Local Inference
Guided setup now detects local inference providers, adds **in-process llama.cpp GGUF inference**, Baseten Model API support, live provider catalog discovery, and model downloads from web and macOS setup.

### New Models
The release adds **Claude Opus 5**, **Kimi K3**, and **GPT Live realtime** support via the OpenAI Platform API.
