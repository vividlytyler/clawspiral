OpenClaw's community continues to produce viral moments and high-profile endorsements. Here's a roundup of notable mentions from the past week.

**Sam Altman: ChatGPT Login Confirmed**

Sam Altman himself confirmed that users can now sign in to OpenClaw with their ChatGPT account and use their subscription directly. "you can sign in to openclaw with your chatgpt account now and use your subscription there! happy lobstering," he posted.

**Elon Musk: X API Integration**

In a surprise announcement, Elon Musk revealed that users can access the X (formerly Twitter) API via OpenClaw. "You can access 𝕏 API via @OpenClaw. We're trying to make it affordable without giving away the shop. Hopefully, this can be useful & fun 💫"

**Satya Nadella: Windows Partnership**

Microsoft CEO Satya Nadella acknowledged the partnership at Microsoft Build: "Thanks for joining us, and all the partnership as we make OpenClaw run super well on Windows! 🦞"

**Microsoft Build Presence**

Peter Steinberger (OpenClaw creator) presented at Microsoft Build, where Microsoft Scout — an enterprise-grade always-on autopilot agent powered by OpenClaw — was announced. Over 3,300 people registered for the OpenClaw event at Build.

**Y Combinator: Fastest Growing Project**

Y Combinator highlighted OpenClaw's trajectory: "Peter Steinberger is the creator of OpenClaw, the open-source AI agent that went from a weekend project to the most-starred software repo on GitHub in under 5 months, with 346k+ stars."

**Developer Enthusiasm**

Community members continue to share their experiences: "I'm finally testing @openclaw. This is crazy good, this thing is probably going to run my life," posted one user. Another noted: "The speed of agents in this new version is incredible."
