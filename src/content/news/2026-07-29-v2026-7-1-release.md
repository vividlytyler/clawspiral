OpenClaw v2026.7.1 shipped on July 13th, 2026, marking the project's largest-ever release by community engagement: **3,063 contributions from 532 contributors**. The X announcement racked up 245K views, underscoring continued massive interest in the open-source AI agent platform.

## What's New

**Web UI & Onboarding Overhaul**
The Control UI received a full redesign, and first-run setup now verifies a real model completion before saving a route. Gateway, channel, agent, and plugin setup are now handled through typed, approval-bound operations via Crestodian.

**Major Mobile App Work**
The official iOS, Android, and macOS apps received substantial updates, with Automations now reaching feature parity on mobile.

**New Model Support**
The release adds compatibility for GPT-5.6, Featherless, Claude Sonnet 5, Mythos 5, Meta Muse Spark 1.1, and ClawRouter with dynamic model discovery and managed budget reporting.

**Telegram & Codex Improvements**
Telegram delivery gained rich HTML and markdown preservation, sticker path support, and recovery-aware final delivery. Codex integration added automatic plugin approvals, GPT-5.3 Spark OAuth routing, remote-node exec as a dynamic tool, and more reliable app-server teardown.

**State Safety & Recovery**
Container upgrades now run state migrations and plugin convergence before Gateway readiness. Repeated unclean boots enter a control-plane-safe mode instead of restart flapping.

## Community Scale

The 532-contributor milestone is remarkable for a project that started as a weekend project by creator Peter Steinberger. The OpenClaw Foundation — officially established as a 501(c)(3) in July 2026 — is now paying a full-time team to sustain the project.

The full changelog is available on [GitHub](https://github.com/openclaw/openclaw/releases).
