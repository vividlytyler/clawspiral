OpenClaw 2026.7.2 adds a significant platform expansion: **Quick Chat** is now available on macOS and Linux, bringing a lightweight streaming chat interface to desktop users alongside the existing native and web experiences.

## What Is Quick Chat?

Quick Chat is a fast, minimal chat surface designed for quick interactions without the full overhead of the complete Control UI. It supports **streaming responses**, intelligent **routing** (directing queries to the right agent or model), **context capture** from the local environment, **dictation** input, and per-conversation **model controls**.

With today's update, those capabilities are now available directly from macOS menu bar and Linux desktop environments.

## What's New in This Release

The macOS and Linux Quick Chat additions include:

- **Streaming** — responses stream in real-time as they're generated, matching the behavior of the web interface
- **Intelligent routing** — configurable rules send different query types to different agents, sessions, or model providers
- **Context capture** — pull in local files, clipboard content, or running process state as conversation context
- **Dictation input** — use voice-to-text directly within Quick Chat on supported configurations
- **Model controls** — switch or tune the active model mid-conversation without leaving the interface

## Desktop Integration

On macOS, Quick Chat surfaces as a menu bar app alongside the existing Gateway control, giving users a persistent one-click chat window. On Linux, the integration targets mainstream desktop environments (GNOME, KDE, XFCE) with system tray and shortcut support.

## Broader Desktop Push in 2026.7.2

Quick Chat is part of a wider desktop push in this release, which also includes:

- **Linux desktop integration and signed updates** for improved package management
- **Multi-gateway app support** — manage multiple OpenClaw gateways from a single desktop client
- **Mobile dashboards** — session boards and dashboards accessible from iOS and Android companion apps
